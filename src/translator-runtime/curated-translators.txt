# v1 list (BE-8-5; 26 translators; ~771 KB raw before gzip):
# - Generic frameworks (5) that catch ANY academic page with OG / DOI /
#   embedded metadata: Embedded Metadata, COinS, unAPI, DOI Content
#   Negotiation, plus arXiv.org (the BE-8-4 spike target — kept in v1).
# - Aggregators / platforms (3) that back ~150+ publisher sites between
#   them: HighWire, HighWire 2.0, Atypon Journals. Including these
#   multiplies effective publisher coverage well past the raw 26.
# - Major academic publishers (18): Elsevier (ScienceDirect), Wiley,
#   Springer Nature, PubMed{,Central}, SSRN, JSTOR, IEEE, ACM, SAGE,
#   T&F+NEJM, Cell Press, OUP, Cambridge, Project MUSE, RePEc IDEAS, NBER.
#
# Misses from the AC2 seed (with rationale):
#   - Mendeley (no translator in upstream — Mendeley is a reference
#     manager, not a publisher site)
#   - Open Graph as a standalone (covered by Embedded Metadata)
#   - bioRxiv / medRxiv (no dedicated translators; covered by HighWire +
#     Embedded Metadata since both run on HighWire)
#   - EconStor (no translator in upstream)
#   - ScienceDirect XHR (no separate variant in upstream; ScienceDirect
#     covers both paths)
#
